# 日本铁路客流地图 · React 版

使用 React 19、Vite 和 Canvas 2D。线路、都市圈调查、车站客流和底图数据都包含在项目中。

## 本地运行

需要 Node.js 20.19 或以上的 20.x 版本，或 Node.js 22.12 及以上版本。

```bash
npm ci
npm run dev
```

按终端输出打开本地地址。运行 `npm run build` 可生成适合静态托管的 `dist/`。运行 `npm run preview` 可查看构建结果。

## 功能

- 全国铁路运输密度、2015 年三大都市圈站间客流、车站日均上下车三个视图
- 地图拖拽与缩放、城市快捷定位、新干线和地铁等线路筛选
- 线路、车站、运营商搜索，线路区间和同一车站的运营商切换
- 财年选择、历年客流图表、中文、日文和英文界面

全国运输密度包含 2018–2025 财年的可用记录，车站客流包含 2018–2024 财年的可用记录。都市圈视图使用 2015 年调查里能匹配到线形的区间。详见 [DATA.md](./DATA.md)。

## 代码入口

| 路径 | 内容 |
| --- | --- |
| `src/App.jsx` | 页面状态和筛选、搜索与地图联动 |
| `src/RailPanel.jsx` | 筛选器、结果列表和线路或车站详情 |
| `src/MapView.jsx` | React 地图组件、图例和缩放控件 |
| `src/rail-map.js` | Canvas 绘制、平移缩放、轨道命中检测 |
| `src/data.js` | 数据加载、索引与统计口径 |
| `public/data/` | 已处理的地图和客流数据 |
| `scripts/prepare_data.py` | 从公开资料重建地图数据 |
